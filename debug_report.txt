Найденные ошибки:
1. db_products.py падал с TypeError, если у товара цена NULL (Product.total()).
2. При пустом названии в консоли выводилось пустое место вместо названия.

Как исправлены:
1. В Product.__init__: price = price if price is not None else 0
   (так же для количества).
2. В Product.__init__: name = name if name else "[Без названия]".
